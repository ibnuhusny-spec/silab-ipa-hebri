Aksi Sinkronisasi Data

Anda dapat mengunggah seluruh data inventaris, civitas, peminjaman, dan struktur organisasi dari lokal ke database cloud Supabase, atau menarik data terbaru dari cloud ke aplikasi ini.

Skrip SQL Tabel Supabase

Petunjuk Penting Setup Supabase

  1. Langkah 1 (Buka Supabase): Buka dashboard akun Supabase Anda di supabase.com/dashboard.
  2. Langkah 2 (Buat Project Baru atau Unpause): Jika project yang ada terkena limit exceed_egress_quota, Anda dapat membuat project baru gratis (Free Tier gratis 2 project, 500MB DB, 1GB Storage, 5GB bandwidth) atau melepas limit di menu Settings > Billing > Usage Caps.
  3. Langkah 3 (Eksekusi Skrip SQL): Buka menu SQL Editor di project Supabase Anda, buat New Query, tempelkan skrip dari tombol "Salin Skrip SQL Schema" di atas, lalu klik RUN. Ini akan otomatis membuat tabel silab_alat, silab_fasilitas, silab_bahan_kimia, silab_members, silab_loans, silab_org_structure, dan Storage Bucket silab-assets.
  4. Langkah 4 (Hubungkan & Unggah): Salin URL & Anon Key dari project tersebut, tempelkan pada kolom di atas, klik Simpan & Hubungkan, lalu klik "Unggah Semua Data Lokal ke Supabase". Selesai!
